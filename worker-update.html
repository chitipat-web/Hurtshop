อัปเดตตัวตรวจสลิป

3 ขั้น ใช้เวลาราว 3 นาที · หน้านี้ทำงานในเครื่องคุณเท่านั้น รหัสลับไม่ถูกส่งไปไหน

1คัดลอกโค้ดเดิม

  1. กดปุ่มด้านล่าง → ล็อกอิน Cloudflare → กด Edit code (มุมขวาบน)
  2. คลิกในช่องโค้ด กด Ctrl+A แล้ว Ctrl+C (Mac ใช้ ⌘)
  3. กลับมาหน้านี้ แล้ววางในช่องด้านล่าง
เปิด Cloudflare (rudybank) ↗

    ไม่เจอบางค่าในโค้ดเดิม — ใส่เองตรงนี้:

    2คัดลอกโค้ดใหม่

    3วางใน Cloudflare แล้วกด Deploy

    1. กลับไปหน้า Edit code ของ rudybank
    2. คลิกในช่องโค้ด กด Ctrl+A แล้ว Ctrl+V (วางทับทั้งหมด)
    3. กด Deploy มุมขวาบน — เสร็จ

    ทดสอบ: แนบสลิปมี QR ในแอป 1 ใบ → ต้องบันทึกได้ และหน้าตั้งค่า "ตรวจสลิปกับธนาคาร" คำว่า "ประมาณ" จะหายไป

    ถ้ามีปัญหา: วางโค้ดเดิม (ในช่องขั้นที่ 1) กลับไปแล้วกด Deploy — ทุกอย่างกลับเหมือนเดิม

    เสร็จแล้วปิดหน้านี้ได้เลย · ช่องทั้งหมดจะถูกล้างเมื่อปิดหน้า
